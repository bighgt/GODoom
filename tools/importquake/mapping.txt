# Doom texture / flat  ->  Quake 1 texture pack file (assets/import/Quake1_Textures.pk3)
#
# One entry per line:   <DOOM_LUMP>  <quake-file-stem>  <wall|flat>
#   - DOOM_LUMP        the name a Doom level references (TEXTURE1 name or flat lump)
#   - quake-file-stem  a .tga in the pk3's textures/ folder, without path or extension
#   - wall|flat        which output folder it lands in (assets/textures/quake1/walls|flats)
#
# Blank lines and lines starting with '#' are ignored. tools/importquake reads
# this, converts each referenced .tga to PNG, and writes it as <DOOM_LUMP>.png.
# It is a curated, subjective pairing: Doom and Quake share no texture names, so
# every row here is a judgement call about which Quake surface best stands in for
# a Doom one. Names not listed simply keep whatever they resolve to today (the
# assets/textures/walls|flats hi-res PNG, else the WAD). Edit freely and re-run.
#
# The pk3 used here is the Quake 1 "map source" community texture set (ikbase /
# Rubicon / Zerstorer-era art). It leans tech-base and medieval-stone, so Doom's
# UAC / brown-brick / hell themes map onto it more naturally than its skin/flesh
# textures do.
